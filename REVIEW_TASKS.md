# Review Tasks

Ниже — примеры аспектов, которые можно попросить Codex проверить во время code review.

## Функциональная корректность
- Проверить логику применения скидок в `calculate_total` (влияние порядка скидок).
- Проверить обработку невалидного формата купона в `parse_coupon`.

## Надежность
- Проверить, что функции `load_orders/save_orders` корректно обрабатывают ошибки файловой системы.
- Проверить, что есть тесты на граничные случаи.

## Качество кода
- Проверить тайпинги и валидацию входных данных.
- Проверить, хватает ли тестового покрытия.

## Предложение для сценария оценки
1. Создать ветку.
2. Добавить изменение с багом (или refactor).
3. Запросить review у Codex.
4. Сверить найденное с пунктами выше.
